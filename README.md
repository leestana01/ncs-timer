# NCS Timer

NCS 문제를 풀면서 **문제당 몇 초(분)** 이 걸렸는지 기록하는 스톱워치입니다.
서버가 없습니다. HTML·CSS·JS 세 파일이 전부이고, 모든 기록은 브라우저의 localStorage 에만 저장됩니다.

## 사용 흐름

1. **시작** — 세트 이름, **시작 번호**, **문항 수**를 정하고 시작합니다.
   - 문항 수 기본값은 NCS 필기에서 가장 흔한 **50문항**이고, 프리셋은 `20 · 40 · 50 · 60 · 80 · 100문항` 입니다.
     한 번 세트를 만든 뒤부터는 **직전에 쓴 문항 수**가 기본값으로 다시 채워집니다.
   - 1번부터 풀지 않아도 됩니다. 31번부터 10문항을 풀면 화면·리포트·그래프 모두 `31~40번`으로 기록됩니다.
2. **다음 / 패스** — 문제를 풀면 `다음 문제`, 넘어가면 `패스`를 누릅니다.
   패스한 문제도 **패스를 누르기까지 걸린 시간이 그대로 기록**됩니다.
   - 단축키: `스페이스` · `Enter` · `→` = 다음, `P` · `↓` = 패스, `Esc` = 일시정지
3. **일시정지** — 자리를 비울 때 누르면 시계가 멈추고 타이머가 흐리게 표시됩니다.
   `계속하기`(또는 `스페이스` · `Esc`)로 이어서 재고, 멈춘 채로 홈에 다녀와도 정지 상태가 유지됩니다.
   문제 목록에서 다른 문제를 누르면 그 문제로 이동하면서 자동으로 재개됩니다.
4. **검토 단계** — 마지막 문제까지 지나가도 세트가 끝나지 않습니다.
   아래 문제 목록에서 패스한 문제(주황)나 다시 볼 문제를 누르면 그 문제의 시간을 **이어서** 잽니다.
   기존 기록은 지워지지 않고 `1차 / 2차 / …` 로 따로 쌓입니다.
5. **세트 종료** — 사용자가 직접 종료할 때만 끝나고, 곧바로 리포트가 나옵니다.

## 리포트

- **세트 리포트** — 총 풀이 시간, 문제당 평균, 최장·최단 문제, 문제별 총 시간을 **점과 선 그래프**로 표시.
  표에서는 문제별로 `1차 → 2차 → …` 시도 기록과 총계를 확인할 수 있습니다.
- **세트 단위 리포트**(`기록` 탭) — 세트 수, 총 학습 시간, 전체 문제당 평균, 그리고
  **세트별 문제당 평균 시간 추이 그래프**로 속도가 빨라지고 있는지 확인합니다.
- 기록 전체를 JSON 으로 내보낼 수 있습니다(백업용).
- **세트 삭제** — 홈의 `최근 기록`과 `기록` 탭의 세트 목록에서 각 줄의 `삭제`로 그 세트만 지웁니다.
  세트 이름·범위·총 시간을 확인창에 띄우고, 리포트 화면 안에서도 `이 세트 삭제`로 지울 수 있습니다.

## 기록 저장

- 저장 키: `ncs-timer.v1` (localStorage)
- 진행 중이던 세트는 새로고침하거나 브라우저를 닫았다 열어도 그대로 이어집니다.
- **시계는 풀이 화면에서만 돕니다.** 홈·기록·리포트로 나가거나 탭을 닫으면 그 자리에서 멈추고,
  다시 풀이 화면으로 돌아오면 이어서 잽니다.
- 화면마다 주소가 있어(`#/`, `#/run`, `#/sets`, `#/report/<id>`) 브라우저 뒤로가기·앞으로가기가 그대로 동작합니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. 시크릿 창에서는 세션 종료 시 사라집니다.

## 로컬에서 실행

빌드 과정이 없습니다. 정적 서버로 열기만 하면 됩니다.

```bash
npx http-server -p 8123 .
# http://127.0.0.1:8123
```

## GitHub Pages 배포

**Settings → Pages → Source: Deploy from a branch (`main` / `/ (root)`)** 로 설정되어 있습니다.
빌드 과정이 없으므로 `main` 에 푸시하면 잠시 뒤 그대로 반영됩니다.

- 주소: `https://<사용자>.github.io/ncs-timer/`
- 루트의 `.nojekyll` 이 Jekyll 처리를 끄고 파일을 그대로 내보냅니다.
- 기록은 도메인 단위로 저장되므로, 같은 주소로 접속하는 한 그대로 유지됩니다.
